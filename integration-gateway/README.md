# Integration Gateway

Gateway transport HTTPS ke/dari Google Chat. Memverifikasi token Google, meneruskan callback ke hub dengan JWT relay, dan membatasi transport keluar ke endpoint Google yang ditetapkan. Tidak menyimpan database bisnis atau private key Google.
